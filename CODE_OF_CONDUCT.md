# code of conduct

this project follows the [contributor covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

in short: be kind, assume good faith, give and take feedback gracefully, and keep
discussion about the work. harassment, insults, and personal or political attacks
aren't welcome here, in issues, pull requests, or anywhere else the project lives.

## reporting

if someone's behavior makes this project a worse place to be, report it privately
to the maintainers through the contact details on the maintainer's github profile.
reports are handled confidentially. maintainers may remove comments, commits, or
contributions that break this code, and may ban repeat offenders.

the full text of the covenant, including enforcement guidelines, is at the link
above and applies in full.
